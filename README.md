🍽️ Restaurant Management System

A Python-based Restaurant Management System designed to manage food orders and calculate customer bills easily.

📌 About Project

This project is developed using Python. It allows users to view the restaurant menu, select food items, enter quantities, and calculate the total bill.

✨ Features

- Display Restaurant Menu
- Select Food Items
- Add Multiple Food Items
- Calculate Total Bill
- User-Friendly Interface

🛠️ Technologies Used

- Python
- VS Code

▶️ How to Run

1. Download or clone this repository.
2. Open the project in VS Code.
3. Run the Python file.
